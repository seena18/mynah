# mynah v1.0.1

v1.0.1 ships the current React interface and fixes the interactions used in the
launch workflow: project creation, line reordering, preview invalidation, and
the bottom action bar layout.

## Install

```bash
git clone --branch v1.0.1 https://github.com/seena18/mynah
cd mynah
uv run run.py
```

The first launch creates the Python environment and anonymously downloads the
pinned 2.99 GB model checkpoint. Allow roughly 4 GB of free disk space.

## What changed

- Rebuilt the interface in React while keeping the local, single-process setup.
- Added visible drag movement and displacement when reordering lines.
- Standardized the interface terminology on **line**.
- Invalidated the stitched preview immediately after deleting or changing a
  line, so Preview and Export always reflect the saved sequence.
- Saved active text edits before generation and rerolls.
- Fixed the **New project** flow and project-modal focus behavior.
- Kept Generate, Preview, and Export in a stable full-width action bar.
- Confirmed that Export downloads the current stitched WAV.

## Validation

- 56 automated unit and browser tests pass.
- The committed frontend build matches the React source.
- Dependency resolution passes from the lockfile.
- The real preview and export path was exercised on Apple Metal.
- Fresh native Windows 11 and WSL2 CUDA validation remains documented in the
  [platform report](https://github.com/seena18/mynah/blob/v1.0.1/docs/platform-validation-2026-09-08.md).

Mynah is a local, single-user tool and binds to loopback by default. It does not
add authentication when exposed with `--host 0.0.0.0`. Clone only voices you own
or have permission to use. Generated audio carries Chatterbox's upstream Perth
watermark.
