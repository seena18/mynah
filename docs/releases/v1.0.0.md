# mynah v1.0.0

Clone a voice locally, turn a script into speech, and regenerate a single bad
line without regenerating the whole narration.

The attached 85-second demo opens with the same words spoken by the original
voice and its clone, then walks through the app.

## Install

Install [uv](https://docs.astral.sh/uv/) and Git, then:

```bash
git clone --branch v1.0.0 https://github.com/seena18/mynah
cd mynah
uv run run.py
```

The app opens at http://localhost:8765. First start downloads approximately
3 GB of model files. No account, API key, or Hugging Face login is required.
Python 3.10–3.12 is supported; uv selects a compatible interpreter.

This is a source release, run from its checkout. Installation details and the
pip alternative are in the [README](https://github.com/seena18/mynah/blob/v1.0.0/README.md).

## Included

- Voice recording and upload, with reusable compiled voices across projects.
- Script splitting, per-line generation and re-roll, and an interruptible queue.
- Reuse of unchanged takes; editing a line back restores its cached audio.
- Stitched preview with waveform seeking and line highlighting, plus WAV export.
- Editable pauses and export-time silence trimming, loudness matching and fades.
- Path validation, fresh playback after re-rolls, and saving edits before generation.
- Model code and a fixed, tested model checkpoint for reproducible installation.

## Validation

- Real generation and export on an Apple M1 Pro using Metal.
- Fresh native Windows 11 and WSL2 Ubuntu 22.04 installs on an RTX 4080 SUPER,
  including empty-cache model downloads, CUDA generation, preview, export and Stop.
- 50 passing tests in the local release suite, covering core behavior,
  HTTP/browser flows and checkpoint selection; CI also checks dependencies.

See the [Windows/WSL test report](https://github.com/seena18/mynah/blob/v1.0.0/docs/platform-validation-2026-09-08.md)
for hardware, timings and test scope. The pinned Chatterbox Turbo model revision
is `749d1c1a46eb10492095d68fbcf55691ccf137cd`.

## Limitations

- One generation runs at a time. CPU-only operation has not been validated and
  is expected to be slow.
- Voice quality depends on the reference and generated take. Short lines can
  sound choppy; generation is stochastic and may need a re-roll.
- This is a local, single-user app. It binds to loopback by default and has no
  authentication if explicitly exposed to a network.
- Generated audio carries Chatterbox's upstream Perth watermark.
- Clone your own voice or one you have permission to use.

For existing checkout users, stop the app, fetch and check out `v1.0.0`, then
run `uv run run.py` again. Projects and voices remain in the local `data/`
directory; keep a copy when moving to another checkout.
